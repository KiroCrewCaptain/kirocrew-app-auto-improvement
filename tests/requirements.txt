# Test-only dependencies, pinned. Deliberately NOT at the repository root: a root
# requirements.txt makes a Kiro Crew registry install run pip into the gateway's
# interpreter (and is refused outright on the desktop build). At runtime the app
# needs only the stdlib and aiohttp, which the gateway already provides, and the
# gateway itself.
#
# Kiro Crew is a TEST dependency here, pinned to one commit of its public source:
# the improvement loop drives the host's OS sandbox, its hook manager and transport
# floor, its crew members and their sessions, its redactor and its owner-only file
# helpers, and the suite exercises those real collaborators the way the built-in's
# suite did. The app imports none of it at module level (tests/test_no_host_imports.py);
# it reaches the host only through backend/_host.py, by name.
